# Ученики и сентябрьский срез

Отдельный модуль в проекте отчётов. Сервер получает данные непосредственно из PostgreSQL, локальные слепки не используются. Модуль student-register запускается самостоятельно.

## Запуск

Из этой папки: `npm start`, затем http://localhost:8788.
Или двойной щелчок по `start.bat`.
Используются DB_HOST, DB_PORT, DB_NAME, DB_USER, DB_PASSWORD, DB_SSL из родительского .env. Пароль не передаётся в браузер.
Существующий pg в родительском node_modules подходит. Для автономного переноса выполнить npm install.
Порт: STUDENT_REGISTER_PORT, по умолчанию 8788. Сервер слушает только 127.0.0.1. Внешняя публикация требует авторизации и отдельной настройки доступа.

## Интерфейс

Референс таблицы: розовые первые три столбца, закреплённые первые три столбца и шапка, ссылка на курс, комментарий, статус. Есть поиск, фильтры, сортировка, CSV для Excel с UTF-8 BOM.
При открытии выполняется актуальный запрос. Обновление запрашивает базу повторно. Кэш обычного API-запроса — 60 секунд.
«Пример оформления» показывает только условные записи для демонстрации оформления. Это не актуальные записи базы; все имена, цели и идентификаторы примера вымышлены. В CSV примера есть префикс example-.

## Что реализовано в источнике

Чтение в согласованной транзакции REPEATABLE READ READ ONLY с лимитом времени.
Одна запись = student_id + group_id. Включены активные и архивные ученики по проведённым/оплаченным занятиям до текущего времени, с исключением отменённого участия. Преподаватель последнего занятия пары, смена преподавателей отмечается в комментарии.
Класс берётся у ученика; предмет у группы. Курс открывается по стандартному адресу Django admin/course/course/ID/change/.
Срезы связаны с курсом через assignedhomework и topicinhomework. Ответы за сентябрь выбранного года; последняя попытка на задание. Процент = правильные / выполненные задания. Отсутствие ответов не считается нулём.
При нескольких подходящих срезах процент остаётся пустым до явного сопоставления темы.
Готовое learning_goal переносится дословно. При нескольких целях или отсутствии готового текста поле пустое.

## Перед итоговой выгрузкой

Доступ к PostgreSQL из текущей среды пока завершается таймаутом. SQL и поля не удалось проверить на актуальной базе.
Не завершена проверка определения участия без проведённых/оплаченных занятий, статусов уроков/учеников, форматов 3/4/5, повторных попыток, сформированных Django целей и редакторов курса.
В config.json необходимо внести подтверждённые groupFormats, courseLevelsByTag, courseEditors, assessmentTopicIdsByCourse. Формат 1 и статусы 0/1 взяты из задания и тоже требуют сверки при подключении.
Поле reviewed оставлено false; его можно поменять только после проверки полноты источника и бизнес-правил. Ошибка подключения не заменяется слепком или примером.

Проверки: `npm test`.
