# Мой Ломоносов — отчёты

Страница «Ученики и сентябрьский срез» находится в `student-register/`. Код читает актуальную PostgreSQL через сервер Node.js. Локальные слепки не используются.

## Посмотреть оформление через GitHub Pages

В `docs/` подготовлен статический пример с условными учениками, без персональных данных и паролей.
В настройках репозитория: **Settings → Pages → Deploy from a branch → main → /docs → Save**.
Это только пример интерфейса. GitHub Pages не запускает Node.js и не подключается к PostgreSQL. Актуальные отчёты требуют сервера приложения.

## Запуск актуального отчёта

```sh
npm install
# Скопировать .env.example в .env и задать доступ к PostgreSQL на сервере.
npm start
```

Открыть http://localhost:8788. Сервер слушает только localhost.
На сервере Django можно разместить этот процесс за обратным прокси с авторизацией.
Пароль хранится в окружении сервера или в исключённом из Git `.env`.

## Текущий статус

- Интерфейс, фильтры, CSV и тесты реализованы.
- Пример оформления обезличен.
- Подключение к актуальной БД из рабочей среды завершается таймаутом.
- Полнота исторического участия, форматы, дословные сформированные Django цели и правила среза требуют проверки; подробности в student-register/README.md.
- Наличие кода на GitHub не означает, что сервер актуальных отчётов уже размещён.

`npm run build:preview` — обновление статического примера из исходного интерфейса.
